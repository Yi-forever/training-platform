# training-platform

编程培训管理平台（启航编程管理系统）—— 面向中小型编程培训机构的一站式管理平台：学员、课程、班级排课、教师、缴费与统计。

## 当前阶段：第三阶段 · 前后端一体化 + 数据库化（v0.4）

在第二阶段后端的基础上，前端已从 localStorage 演示数据全面切换为调用 `/api/v1` 后端接口；**本版本（v0.4）完成数据库化改造并落地四类身份登录**：

- **框架**：FastAPI + uvicorn（依赖见 `pyproject.toml`），分层架构 `api（路由）→ services（业务）→ db（存储）`；
- **存储**：**关系数据库（SQLAlchemy 2.0 ORM）**，默认 SQLite（`data/app.db`，零配置开箱即用），通过环境变量 `QIHANG_DB_URL` 可一键切换到 MySQL；统一 `accounts` 表承载四类身份（员工 / 教师 / 学员 / 家长），业务实体与旧 JSON 结构的键名一一对应，仓储层 `DB` 对外接口与原 `JsonDB` 完全兼容，service / api 层无需改动即可平滑切换；
- **认证**：自研轻量 Bearer Token（HMAC-SHA256 签名，无额外依赖，接口形状与 JWT 一致），密码 PBKDF2-SHA256 加盐哈希；**四类身份统一登录入口，后端按账号自动识别身份**；
- **身份区分（服务端门禁 + 前端分流）**：
  - **管理后台（学员 / 班级 / 课程 / 教师 / 缴费 / 用户 / 工作台看板）仅员工可见**：相关接口统一收归 `require_admin`，非员工访问返回 403；
  - **教师 / 学员 / 家长走专属门户**：`/portal/overview` 及各身份专属接口（`/portal/teacher/classes`、`/portal/student/profile`、`/portal/parent/children`）按登录身份返回数据，并以 `require_identity` 显式门禁（越权 403）；
  - 前端登录后按身份分流：员工 → `dashboard.html`（管理后台），教师 / 学员 / 家长 → `portal.html`（专属门户）；非员工手动访问后台页会被重定向到门户；新闻 / 资源为全员可读资讯门户（写操作仍受限）。
- **作业与考勤（issue #2）**：
  - **教师**：按自己所带班级布置 / 编辑 / 结束 / 删除作业，查看班级提交情况并逐人批改（0-100 分 + 评语）；按「班级 + 日期」录入考勤（出勤 / 迟到 / 请假 / 缺勤 + 备注），重复保存为更新；
  - **学员**：查看本班作业与截止日期，提交 / 重新提交作业，查看分数与教师评语；查看本人考勤记录；
  - **家长**：查看关联学员的作业提交状态、分数、教师评语与考勤记录，支持按孩子筛选；
  - 服务端按 `require_teacher / require_student / require_parent` 门禁，并校验「班级归属 / 学员归属」；跨班布置、跨班录入、跨教师批改、查看他人孩子均返回 403；提交按「作业 + 学员」唯一，重新提交会清空旧批改。
- **课表与课次考勤（本期新增）**：
  - 班级的「上课时间」文本（如 `周六 09:00-10:30`、`周一/三/五 09:00-12:00`）解析为「星期 + 起止时间」，按开班/结课日期自动展开为具体课次（`SK001…`）；
  - **员工课表**（`timetable.html`）：周视图（周一至周日）、按班级/教师筛选、上一周/本周/下一周切换，点击课次维护授课主题与状态，支持按班级「补齐课表」；
  - **教师**：门户「我的课表」查看近两周课次，一键跳转对应课次考勤；可维护本人班级课次的主题与状态；
  - **学员 / 家长**：只读查看本班 / 关联学员课表（家长支持按孩子筛选）；
  - **考勤联动**：保存课次考勤后该课次自动标记「已完成」；教师可按月查看班级考勤统计（出勤/迟到/请假/缺勤次数与出勤率），学员与家长端展示出勤率汇总；
  - 权限：教师只能调整本人班级课次（跨班 403）；学员/家长仅能查看本人或关联学员课表；排课文本无法识别时补齐课表返回 400。
- **API 前缀**：`/api/v1`，统一响应壳 `{code: 0, message, data}`，业务异常返回中文提示（400/401/403/404/409）；
- **前端接入**（本阶段新增）：
  - `web/js/api.js`：统一 API 客户端 —— Bearer 注入、响应壳解析、401 自动清理会话并跳登录、全量资源方法（CRUD + 缴费确认/作废、新闻阅读、资源下载、工作台统计、系统设置）；
  - `web/js/common.js`：`boot()` 页面启动入口（布局渲染 + 会话校验）+ `hydrate()` 全量缓存拉取；写操作成功后重新 `hydrate()`，本地视图与服务器始终一致；
  - 登录支持「记住我」（localStorage 持久会话 / sessionStorage 会话级）；
  - 普通用户可在「个人信息」页自助修改姓名/手机/邮箱（`PUT /auth/profile`）与密码；用户列表仅管理员拉取，非管理员访问相关接口返回 403；
  - 「系统设置」的演示数据重置改为调用 `POST /settings/reset`（服务端全量恢复种子状态），非管理员只读。
- **业务规则**（与设计文档一致，均有验证脚本覆盖）：
  - 取号规则 `JS/KC/BJ/XS/JF/XW/ZY + 3 位序号`，软删后不复用；
  - 删除保护：教师被班级引用、课程被班级引用、班级有学员时禁止删除；
  - 开班校验：停售课程不可开班、离职教师不可排课；
  - 缴费状态机：待确认 → 已支付 / 已作废（已退款为终态），收入统计仅计「已支付」；
  - 学员删除时级联归档其名下缴费记录（同一事务）；
  - 缴费详情口径：应缴 = Σ 有效账单，已缴 = Σ「已支付」流水，欠费 = 差额（≥ 0）；「待确认」不计入已缴，无账单的历史流水不参与欠费计算；家长仅可查看关联学员；
  - 系统至少保留一个启用的超级管理员，不能删除/禁用/降级自己。

### 快速启动

```bash
python -m uvicorn app.main:app --reload --port 8000
# 浏览器访问 http://127.0.0.1:8000 （自动跳转登录页，前端与 API 同源部署）
# 交互式 API 文档：http://127.0.0.1:8000/docs
```

登录账号见下表（`admin / admin123`、`jiaowu / 123456` 等）。

### 后端验证脚本

```bash
python scripts/verify_api.py        # 113 项 API 冒烟断言（隔离临时 SQLite，不污染 data/app.db）
python -m pytest tests/ -q          # 65 项：四类身份 / 门禁 / 作业批改 / 考勤幂等 / 课表生成 / 缴费详情 等单元与集成测试
```

`scripts/verify_api.py` 使用隔离的临时数据库跑 **113 项冒烟断言**（认证/权限、自助资料更新、用户保护、删除保护、状态机、统计口径、排序、设置联动、重置数据等）。`tests/` 下为 pytest 测试套件（**65 项**），覆盖四类身份登录、身份门禁、数据库增删改查、学员级联删除、作业提交与批改权限、家长可见性、考勤幂等与跨班拦截、课表解析与课次生成、课次考勤联动、学员/家长缴费详情的越权与对账口径等业务规则。

### 技术说明

- 数据全部来自 `/api/v1` 后端（`web/js/api.js` 统一封装请求与 token 会话）；
- 页面通过 `boot(pageKey)` 启动：同步渲染布局校验会话，再 `hydrate()` 并行拉取全部集合到 `window.DB` 缓存，写操作成功后重新拉取，保证与服务器一致；
- 会话：JWT token + 用户信息，按「记住我」选择存 localStorage（持久）或 sessionStorage（关闭浏览器失效）；token 过期后任意请求触发 401，自动清理会话并跳转登录页；
- 「系统设置 → 演示数据管理」调用后端一键重置（服务端恢复种子状态）；
- 通用组件（侧边栏布局、模态框、Toast、确认框、徽章、头像、权限过滤）由 `web/js/common.js` 提供。

## 数据库配置

- 默认：`sqlite:///<项目>/data/app.db`（首次启动自动建表并写入种子数据，无需任何配置）；
- 切换 MySQL：设置环境变量 `QIHANG_DB_URL=mysql+pymysql://user:pass@host:3306/qihang`，其余代码无需改动；
- 测试隔离：`scripts/verify_api.py` 与 `tests/` 均使用临时数据库，互不污染。
